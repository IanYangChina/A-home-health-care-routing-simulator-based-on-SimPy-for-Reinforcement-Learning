Simulation rules

The simulator uses the benchmark’s appointments, nurses, skill constraints, and travel model. An assignment needs a feasible start, a wait of no more than 40 minutes, and a projected return by minute 480. The score awards 10 points per completed visit and charges 0.03 per travel minute and 0.15 per waiting minute. Each visit still unserved at shift end costs 8 points.

Runs are reproducible with the same seed and actions in this browser simulator. The JavaScript service-time generator differs from the Python generator used in the measured experiments.
