Round 9 · Full nurse roster and longer returns

PI direction and measured experiment report

21 Nov 2026 · family runner logs 16:35:09–16:51:03 UTC

PI input

ny requested the full roster to show every nurse in every phase, DQN return lengths of 32 and 64, two higher PPO discounts, short-wait and ACO guidance for both agents, and a stronger waiting penalty on all four layouts.

Read the two pre-round diagnostics.

Agent work

Added an optional normalized roster with one row per nurse. It includes their last confirmed location, skill, phase, assignment, ready-queue position, estimated minutes to availability, post-release shift time, and completed count. For an ongoing visit, the estimate conditions on service still being in progress and uses the duration model. It does not use the simulator’s hidden duration draw. Kept the 512-decision PPO rollout and λ = 1. Chose γ = 0.998 and 0.9995 and doubled the waiting cost from 0.15 to 0.30 points per nurse-minute. Carried forward the other tuned settings.

Within Round 9, each return setting was crossed with both guides on each layout. Final checkpoints used greedy assignment. The 0.30 and 0.05 scores each apply a common waiting cost to every policy. The comparison with Round 8 uses a common 0.30 score and reflects the combined observation, training reward and return changes.

Computation

Ran 96 fits of 12,288 decisions each using three training seeds per configuration. Recorded 8,277 complete training shifts and evaluated 1,152 learned-policy shifts. The comparison reused 96 matched Random and ACO shifts.
