## Core principles

- Keep codes minimalistic, don't write extra functions or codes for things that the PI doesn't request.
- Always communicate briefly what you have done and found and about to do with subagent delegation.
- Make the smallest change that satisfies the task. Do not refactor unrelated code.
- Preserve uncertainty. It is acceptable to conclude that a property is unknown or unobservable.
- Never use hash code consistency check for any scripts/implementation/files/commits.
